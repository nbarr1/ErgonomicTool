# Method specifications

Each method has one specification here, named `<method-id>.md`. A specification records every equation, constant, lookup table, input definition, measurement instruction, valid input range, output definition, interpretation threshold, and stated limitation, with the page, table, or equation number for each item. No code is written for a method until its specification is approved.

Every specification is a draft until the product owner, who is also the reviewer (decision D-110), approves it.
